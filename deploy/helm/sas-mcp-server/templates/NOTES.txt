{{- if .Values.server.allowRawBearer }}

NOTE: allowRawBearer is on. ANY JWT signed by this Viya's SASLogon is accepted
as a full MCP credential — the verifier sets audience=[] with no required
scopes, so tokens minted for other clients (e.g. `sas-viya auth login`) work
too, with no client registration and no consent screen. Set
server.allowRawBearer=false to require the PKCE flow.
